# Secretly

Автор и правообладатель: **Юрий Архангельский**. Приложение выпускает в
магазинах **SIA Secretly**, Валмиера, Латвия.

**Скачать:** [Google Play](https://play.google.com/store/apps/details?id=com.secretly.secretly_app) ·
[App Store](https://www.secretlyapp.com/download) ·
[secretlyapp.com](https://www.secretlyapp.com)

Мессенджер со сквозным шифрованием: сообщения шифруются на устройстве отправителя
и расшифровываются только на устройстве получателя. Учётная запись — ключ,
созданный на устройстве: ни телефона, ни почты, ни аналитики.

## Чего нет в этой выкладке

Здесь только исходный код. Сознательно не публикуются:

| Что | Почему |
|---|---|
| Иконки, стикеры, обои, оформление профиля | лицензии разрешают использование в приложении, но не распространение файлами |
| Настройки Firebase (`google-services.json`, `GoogleService-Info.plist`) | заведите собственный проект Firebase — так делают все выложенные клиенты |
| Внутренние документы: разборы отказов, планы, runbook-и | к проверке кода отношения не имеют |
| Хранилища подписи и любые ключи | их здесь нет и не будет |

Сборка запускается, часть оформления будет пустой — это ожидаемо. Шрифты
включены вместе с их лицензиями (`apps/flutter/secretly_app/assets/fonts/`).

## Что здесь есть

| Каталог | Что внутри |
|---|---|
| `apps/flutter/secretly_app/lib` | клиент: интерфейс, транспорт, локальное хранилище |
| `apps/flutter/secretly_app/lib/ratchet` | Double Ratchet v3 и X3DH — ядро шифрования |
| `apps/flutter/secretly_app/lib/security` | ключи устройства, резервные копии, номера безопасности |
| `server/keys` | сервер ключей: связки предключей, права, подписанная конфигурация |
| `server/relay` | ретранслятор: доставка, очереди, пробуждение пушами |
| `core/rust` | общий криптографический код |
| `test` | автотесты клиента |

Платформы: Android 7.0+, iOS 15.5+, macOS, Windows. Восемь языков интерфейса.

## Чего здесь нет и почему

**Художественные ассеты** — стикеры, косметика профиля, иконки, обои, фоны. Их
лицензии не позволяют распространять файлы отдельно от приложения, поэтому в
репозитории остался только код, который с ними работает. Сборка без них
запускается, но часть оформления будет пустой.

**Инфраструктура и эксплуатация** — конфигурации серверов, сценарии
развёртывания, процедуры обращения с ключами. Это карта рабочих систем, ей не
место в публичном доступе.

**Внутренние разборы** — аудиты, отчёты о дефектах, технические задания. Часть из
них описывает вещи, которые ещё чинятся.

## Сборка

Закреплённые версии: Flutter `3.41.7` (файл `.flutter-version`) и Rust `1.93.1`
(`rust-toolchain.toml`). На других версиях сборка может пройти, но совпадения с
тем, что лежит в магазинах, никто не обещает.

```bash
cd apps/flutter/secretly_app
flutter pub get
flutter analyze
flutter test

cd ../../..
cargo test --workspace
```

Работающая сборка требует адресов серверов, которые передаются при компиляции
через `--dart-define`. Без них приложение обращается к `localhost`. Подробно —
[docs/BUILD.md](docs/BUILD.md).
